## 🌟 Highlights & Features

- **⚡ Modern Next.js 15 (App Router)**: Fast server-side optimizations, clean modular architecture, and zero unnecessary dependencies.
- **🎨 Glassmorphic Dark UI**: Custom-tailored obsidian palette (`#080c14`), glowing accent gradients, backdrop-blur surfaces, and sleek typography.
- **📱 Fully Responsive Design**: Pixel-perfect layout across desktop, tablet, and mobile devices with interactive touch menus.
- **🎯 Dynamic Skills Matrix**: Categorized tech stacks across Frontend, Backend, Databases, and DevOps with proficiency badges.
- **📂 Interactive Projects Showcase**: Filterable project gallery featuring real-time WebSockets apps, React utilities, and interactive web games with live demo links.
- **📬 Interactive Contact Hub**: Direct email copy-to-clipboard functionality with instant visual feedback and email client handoff.

## 🚀 Getting Started Locally

### Prerequisites

- Node.js (v18.0.0 or higher)
- npm (v9.0.0 or higher)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Ghawri/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the local development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view your portfolio live.

---

## 📦 Building for Production

To create an optimized production bundle:

```bash
npm run build
```

To run the production server locally:

```bash
npm run start
```
